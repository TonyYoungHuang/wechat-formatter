# 排版猫升级方案：微信小入口内容增长工作台

更新时间：2026-06-29

## 0. 已确认决策

1. 品牌继续使用「排版猫」。
   - 域名和备案已经完成，继续沿用品牌资产。
   - 「排版」天然贴合微信公众号场景，适合作为用户认知入口。
   - 后续从排版延展到微信小入口增长，不需要更换品牌。
2. 新项目全量重建。
   - 不沿用旧前端架构。
   - 不沿用旧排版模块。
   - 旧项目只作为历史经验参考，不作为代码迁移基础。
3. AI 模型接入海外模型中转站。
   - 面向国内创作者，提供他们难以直接接入的海外模型能力。
   - 这是产品卖点之一。
   - 需要在产品中明确模型能力、额度、成本和稳定性边界。
4. 第一版必须支持「多个账号档案」。
   - 账号档案不是微信公众号官方账号授权。
   - 它是用户在排版猫里保存的内容定位资料，例如账号领域、人设、目标读者、产品、语气、禁用表达。
   - 因为产品定位是微信副业 SaaS，多账号是核心价值之一，不应放到很后面。
   - 免费版可限制 1 个账号档案，付费版开放多个账号档案。
   - 多账号用于支持一个用户同时运营多个公众号、小绿书方向、问一问身份或不同副业项目。

## 1. 商业定位

### 一句话定位

排版猫升级为面向小公众号创作者、副业号主、个人 IP 和个体商家的「微信小入口内容增长工作台」。

核心承诺：

> 一个选题，帮你布局公众号、小绿书、搜一搜、问一问、朋友圈五个入口。

### 不再主打

- 不再把「一键排版」作为主卖点。
- 不做洗稿、搬运、伪原创、自动刷量、违规绕审。
- 不承诺「保证爆款」「保证涨粉」「保证排名」。

### 新主卖点

- 帮用户找到值得写的选题。
- 帮用户把一个选题拆成多种微信生态内容形态。
- 帮用户做搜一搜关键词布局。
- 帮用户写问一问回答和互动问题。
- 帮用户生成小绿书短图文和朋友圈转发文案。
- 帮用户做发布前合规、标题、AI 味、排版检查。

## 2. 目标用户

### 核心用户

1. 公众号副业创作者：粉丝 0-5000，想靠流量主、资料包、社群、咨询变现。
2. 个人 IP：职场、教育、心理、AI 工具、副业、亲子、知识付费等方向。
3. 个体商家：本地服务、培训机构、工作室、课程顾问、私域成交型商家。
4. 小团队运营者：一个主体管理多个公众号/视频号，需要一题多发和排期。

### 付费理由

- 不知道每天写什么。
- 不知道微信生态里有哪些入口能发。
- 不知道搜一搜怎么布局关键词。
- 不知道问一问怎么回答能引导关注。
- 不知道小绿书怎么做图片页脚本。
- 不知道文章怎么结尾才能导向私域/资料包/咨询。
- 怕广告法、夸大宣传、诱导分享、AI 味太重。

## 3. 产品核心闭环

### 主流程

1. 用户输入：领域、账号定位、目标用户、产品/服务、想变现方式。
2. 系统生成：一组可写选题。
3. 用户选中一个选题。
4. 系统一键拆解为五个入口：
   - 公众号长文
   - 小绿书短图文
   - 搜一搜关键词内容
   - 问一问回答/讨论
   - 朋友圈转发文案
5. 用户进入编辑器修改。
6. 系统做发布前检查。
7. 用户复制到微信公众平台/问一问/朋友圈发布。
8. 用户保存为内容项目，后续复盘和复用。

### 产品命名建议

可保留主品牌「排版猫」，但副标题必须升级：

- 排版猫：微信内容增长工作台
- 排版猫：公众号副业创作者的内容分发工具
- 排版猫：一个选题，布局微信五个入口

## 4. 功能设计

### 4.1 工作台首页

首页不是营销页，而是登录后直接进入工作台。

核心布局：

- 左侧：内容项目、账号定位、选题库、模板库。
- 中间：选题输入与五入口生成结果。
- 右侧：入口预览、合规分数、SEO 建议、发布清单。

关键组件：

- 今日建议选题
- 五入口生成按钮
- 最近内容项目
- 待发布清单
- 搜一搜关键词机会
- 问一问待回答问题

### 4.2 账号定位库

每个用户可以维护多个账号档案：

- 账号名称
- 领域
- 人设
- 目标读者
- 产品/服务
- 变现方式
- 禁用表达
- 常用 CTA
- 语气风格

作用：

- 让 AI 生成内容时不再泛泛而谈。
- 支持一个用户运营多个公众号/小号。

### 4.3 选题库

功能：

- 按领域生成选题。
- 标记选题类型：涨粉、搜索、转化、信任、互动、活动。
- 标记适合入口：公众号、小绿书、搜一搜、问一问、朋友圈。
- 保存选题状态：待写、生成中、已发布、已复用。

MVP 先做：

- 选题生成
- 选题保存
- 选题一键拆解

P1 再做：

- 热点日历
- 行业题库
- 用户自建素材库

### 4.4 五入口生成器

#### 公众号长文

生成：

- 标题候选
- 摘要
- 文章大纲
- 开头
- 正文草稿
- 小标题
- 结尾 CTA
- 排版建议

#### 小绿书/图片文字

生成：

- 64 字以内标题候选
- 1000 字以内短文案
- 图片页脚本
- 3:4 图片页文案
- 封面文案
- 朋友圈转发卡片文案

不做：

- 不承诺小绿书官方推荐。
- 不做小红书搬运改写。

#### 搜一搜

生成：

- 主关键词
- 长尾关键词
- 搜索型标题
- 摘要前 100 字优化建议
- 问答型结构
- 关键词自然嵌入建议

不做：

- 不承诺排名。
- 不做关键词堆砌。

#### 问一问

生成：

- 用户可能会问的问题
- 回答草稿
- 讨论发起话术
- 回答后的关注引导
- 可转成公众号文章的问答结构

不做：

- 不做自动批量回答。
- 不做医疗、金融、投资等高风险承诺。

#### 朋友圈

生成：

- 转发理由
- 个人视角短文案
- 评论区引导
- 私域成交 CTA
- 资料包领取话术

不做：

- 不做诱导分享。
- 不做夸大收益承诺。

### 4.5 发布前检查

检查项：

- 广告法极限词
- 夸大收益/效果承诺
- 医疗、金融、教育等敏感表达
- 诱导分享/诱导关注风险
- 标题党风险
- AI 味过重
- 搜索关键词覆盖
- 阅读节奏
- CTA 是否自然
- 小绿书字数/图片页数量

输出：

- 风险等级
- 具体问题
- 推荐改法
- 一键替换建议

### 4.6 内容项目管理

一个内容项目包含：

- 原始选题
- 五入口内容版本
- 编辑历史
- 发布时间
- 发布链接
- 阅读/互动数据手动记录
- 复盘备注

MVP 先支持手动记录，不强依赖微信接口。

## 6. UI 设计方向

### 总体气质

这是面向创作者的工作台，不是营销型大屏。

关键词：

- 清晰
- 高效
- 温和
- 有一点创作感
- 不花哨
- 不堆卡片

### 推荐布局

#### 桌面端

- 顶部：当前账号、套餐、生成额度、快速新建。
- 左侧栏：项目、选题、模板、工具、设置。
- 主工作区：输入/编辑。
- 右侧栏：入口预览、检查结果、发布清单。

#### 移动端

- 底部 Tab：选题、生成、编辑、检查、我的。
- 生成结果以分段卡片呈现。
- 支持一键复制某个入口文案。

### 色彩建议

保留「猫」的品牌记忆，但不要再做重度可爱风。

建议：

- 主色：微信生态绿色，但降低饱和度。
- 辅色：墨色、浅灰、米白。
- 风险提示：红/橙。
- 成功提示：绿色。

### 关键交互

- 五入口结果用 Tab 切换。
- 发布前检查用分数和问题列表。
- 选题库支持状态拖拽。
- 生成内容支持局部重写。
- 所有结果支持复制、保存、导出。

## 7. 技术路线建议

### 是否沿用旧项目

建议：

- 品牌、域名、部分支付经验可以沿用。
- 旧的一键排版逻辑可以作为「公众号排版模块」保留。
- 前端主架构建议重构。
- 后端从 Express + SQLite 升级为更适合 SaaS 的架构。

### 推荐技术栈

#### 前端

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Tiptap 富文本编辑器
- TanStack Query
- Zustand 或 Jotai

#### AI 生成层

- Vercel AI SDK
- 模型适配层：OpenAI 兼容接口 + 国内模型接口
- 支持流式输出
- 支持 prompt template 版本管理
- 支持生成任务日志与额度扣减

#### 后端

优先方案：

- Next.js API Routes / Server Actions 起步
- PostgreSQL
- Prisma ORM
- Redis 做缓存和队列
- BullMQ 或 Inngest 做长任务

如果需要独立后端：

- NestJS + PostgreSQL + Prisma

#### 数据库

核心表：

- users
- workspaces
- accounts
- personas
- topics
- content_projects
- content_variants
- generation_jobs
- compliance_reports
- templates
- cta_templates
- subscriptions
- usage_logs
- payments

#### 支付

面向中国大陆：

- 微信支付
- 支付宝
- 后续可加兑换码/人工开通

#### 部署

中国大陆优先：

- 腾讯云轻量服务器或 CVM
- 宝塔/Nginx
- PostgreSQL 托管或自建
- Redis
- HTTPS
- 域名备案

如果前端想更现代：

- 前端可独立部署，但中国大陆访问和备案要优先考虑。

## 13. 风险和边界

### 主要风险

- 微信入口规则变化。
- 用户误以为工具保证流量。
- AI 生成内容同质化。
- 合规风险，尤其是医疗、金融、教育、收益承诺。
- 生成成本失控。

### 产品边界

- 只做创作辅助，不做自动化刷量。
- 只做发布前建议，不做绕审。
- 只做搜索友好建议，不承诺排名。
- 只做内容复用，不做搬运洗稿。
- 首版排版只支持公众号 HTML 复制，不做复杂模板市场。
- 首版图片能力只做提示词和页面脚本，不实际调用图片生成模型，但预留后续图片生成接口。
