# 排版猫产品原型设计稿

更新时间：2026-06-29

产品定位：

> 排版猫是面向微信副业创作者的内容增长工作台。一个选题，帮你布局公众号、小绿书、搜一搜、问一问、朋友圈五个入口。

本文件用于确认产品原型、页面结构、功能优先级和核心交互。确认后再进入代码实现。

## 2. 公开首页原型

### 2.1 首屏

首屏目标：

- 让用户 5 秒内知道排版猫现在不只是排版，而是微信内容增长工作台。
- 直接引导用户试用「一个选题生成五入口内容」。

布局：

- 顶部导航：
  - Logo：排版猫
  - 免费工具
  - 模板库
  - 教程
  - 价格
  - 登录
  - 开始使用

- 首屏主文案：
  - H1：一个选题，布局微信五个入口
  - 副标题：用排版猫把公众号文章、小绿书、搜一搜、问一问、朋友圈一次性生成出来，适合副业号主、个人 IP 和小团队。

- 首屏输入框：
  - Placeholder：输入一个选题，比如“普通人做公众号副业还有机会吗”
  - 按钮：生成五入口内容

- 首屏右侧/下方预览：
  - 五个入口标签：
    - 公众号
    - 小绿书
    - 搜一搜
    - 问一问
    - 朋友圈
  - 展示生成结果片段，不展示完整内容。

转化设计：

- 未登录用户可以生成一次预览。
- 查看完整结果、保存项目、复制全部内容需要登录。

### 2.2 第二屏：五入口解释

每个入口用一行说明，不做夸张承诺。

- 公众号：生成长文框架、正文草稿、标题、摘要和 CTA。
- 小绿书：生成短图文文案、图片页脚本、封面标题。
- 搜一搜：生成关键词、搜索型标题、摘要优化建议。
- 问一问：生成问题库、回答草稿、关注引导。
- 朋友圈：生成转发理由、私域互动和资料包领取文案。

### 2.3 第三屏：适合谁

四类用户：

1. 公众号副业新手
2. 个人 IP 创作者
3. 个体商家/本地服务
4. 多账号小团队

每类用户展示一条典型痛点和结果。

### 2.4 第四屏：工作流

五步：

1. 建账号档案
2. 生成选题
3. 一键拆成五入口
4. 编辑和检查
5. 复制发布并复盘

### 2.5 第五屏：价格入口

展示三个套餐：

- 免费版
- 入门版
- 专业版

首屏和价格区都要保留「免费开始」按钮。

## 4. 多账号档案原型

### 4.1 页面目标

让 AI 生成内容时始终知道「这个账号是谁、写给谁、卖什么、不能说什么」。

### 4.2 列表页

展示：

- 账号名称
- 领域
- 目标用户
- 变现方式
- 最近使用时间
- 内容项目数量

操作：

- 新建账号档案
- 编辑
- 复制一份
- 设为默认
- 删除

权限：

- 免费版：1 个账号档案
- 入门版：3 个账号档案
- 专业版：10 个账号档案

### 4.3 创建/编辑表单

字段：

- 账号名称
- 账号类型：
  - 公众号
  - 小绿书方向
  - 问一问身份
  - 个人 IP
  - 商家号
- 内容领域
- 人设描述
- 目标读者
- 读者痛点
- 主要产品/服务
- 变现方式：
  - 流量主
  - 资料包
  - 咨询
  - 课程
  - 社群
  - 本地服务
  - 带货
- 常用 CTA
- 语气风格
- 禁用词/禁用表达
- 参考样文

### 4.4 账号档案完整度

分数：

- 0-40：信息不足，生成结果会偏泛。
- 40-80：可用。
- 80-100：适合稳定生成账号风格。

## 15. 待确认问题

已确认：

1. 免费版每天 1 次生成。
2. 入门版账号档案限制 3 个。
3. 专业版账号档案限制 10 个。
4. MVP 不做真实图片生成，先做图片提示词工具，并预留后续图片生成接口。
5. 排版模块首版只支持公众号 HTML，不做复杂模板市场。
6. 视觉风格改成更轻的微信绿色工作台，不沿用旧网站的深色猫风格。

仍待确认：

1. 入门版和专业版的最终价格暂不确定，系统需要预留价格配置入口。
2. 各套餐生成额度暂不确定，系统需要预留额度配置入口。
3. 首版需要接入支付，因为已有支付资质。
4. 海外模型中转站暂不确定，系统需要预留 OpenAI-compatible 模型接口配置。

开发约定：

- 价格不写死在前端，统一从后端配置读取。
- 额度不写死在前端，统一从套餐权益配置读取。
- 支付系统第一版就设计完整订单和回调链路。
- AI 模型供应商使用 provider adapter 结构，先支持 OpenAI-compatible endpoint。
